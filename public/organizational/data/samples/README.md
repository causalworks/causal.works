# Budget App Dummy Data

This directory contains sample financial data for budget app development and user demos.

## Files

- **chart_of_accounts.csv** — Chart of accounts structure (account codes and categories)
- **budget_lines.csv** — Budget line items with allocations
- **actuals.csv** — Actual spending data for comparison to budget
- **balance_sheet.csv** — Balance sheet entries
- **programs.csv** — Program/project definitions for categorization
- **grants.csv** — Grant income and restrictions

## Usage

These files are used for:
- Design and development of the budget app UI
- Demonstration data for user testing
- Example dataset for users to understand the app's capabilities

Do not use for production data.
